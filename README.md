# SupportPilot AI

Production-oriented NLP system for customer support intent classification.

SupportPilot AI classifies e-commerce customer support messages into 46 intents using a fine-tuned DistilBERT model and exposes predictions through a FastAPI service and an interactive Streamlit dashboard.

This project originated as a machine learning final project and is being independently redesigned, refactored, and productionized as an end-to-end ML engineering portfolio case study.
